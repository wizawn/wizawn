## 🍵 最近在做

- 把复杂的协议观察，整理成**离线、可复现、可审计**的小工具。
- 用清晰的证据分层，区分「看到的」「推测的」和「还不知道的」。
- 喜欢一点国风留白，也喜欢二次元的可爱细节：代码要稳，界面可以俏皮。

## 🧪 两个安全实验室

| 项目 | 方向 |
| --- | --- |
| [`ios-iap-safety-lab`](https://github.com/wizawn/ios-iap-safety-lab) | 用合成数据审计 IAP / entitlement 状态，不接触真实购买与凭据 |
| [`codex-state-audit`](https://github.com/wizawn/codex-state-audit) | 离线审计不透明状态信号，模拟 TTL 与撤销，不连接在线服务 |
